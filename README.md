# 回到七月 · 三角洲巅峰赛观赛手记

一份按日期翻阅的观赛手记：先读背景，选择主播视角或赛事直播回放，再主动揭晓当日战报与阶段汇总。内容在总决赛开赛前停笔，保留总决赛入围情况与录像入口，不写总决赛结果。

包含 18 个时间章节、9 个线上比赛日的赛事录像入口，以及 BBFPS、昊天、林树、XDD 等主播的相关回放、备用版本、来源说明和 21 张资料图片。未查实的个人录像、缺段及分 P 顺序均在对应条目说明。

## 直接部署

这是没有构建步骤的静态网站。整个仓库可以直接交给任何支持静态文件和 JavaScript modules 的网页空间。首页是 `index.html`；请连同 `assets/` 和 `guide.pdf` 一起上传，并保留目录结构。

### GitHub Pages

在仓库的 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，将来源设为主分支的 `/ (root)`，保存后等待发布。项目自带 `.nojekyll`，无需 Jekyll 或 npm 构建。

网页使用相对资源路径，可以部署在域名根目录，也可以部署在项目子路径。换用其他静态托管服务时，发布目录同样选仓库根目录，构建命令留空。

网站的样式、脚本、数据和图片均同站提供，不依赖海外字体、CDN、统计服务或第三方脚本。视频在读者主动打开播放器后由哔哩哔哩提供；每条原站入口始终保留。托管站点和原站能否访问仍取决于读者当时的网络与平台状态。

## 本地查看

在项目目录执行：

```sh
python -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。本地需要 Python 3，网页本身不依赖 Python，也不需要安装任何包。JavaScript module 需要通过 HTTP 服务载入，请使用这个预览方式。

## 文件结构

```text

assets/style.css     版式、响应式布局和组件样式
assets/reader.js     逐章阅读、揭晓战报、图片放大和视频播放器

assets/images/       同站资料图片
guide.pdf            可下载的观赛手记 PDF
image-sources.json   图片的原始来源、正文位置及文件校验值
NOTICE.md            内容与第三方素材权属说明
LICENSE              网站源代码的 MIT 许可
```

## 内容维护

直接编辑 `assets/data.js` 导出的对象即可更新文字、日期、表格与回放。保留 B 站链接中的 BV 号、分 P 参数 `p`、时间参数 `t`，并明确录播日期、完整性和观看起点。新增图片放入 `assets/images/`，引用使用 `assets/images/文件名.jpg` 这样的相对路径，同时填写 `sourceUrl`、`sourceLabel`、`caption` 和 `alt`，更新 `image-sources.json` 中的来源。

普通叙事与赛前图片放在章节的 `intro`、`images`、`watch` 等字段；当日结果、名次、积分与赛后图片放在 `report` 或 `summaries` 中。读者没有主动揭晓时，后者不会插入页面。新章节应继续核对标题、导语、图注和图片替代文字，避免提前透露后续结果。

逐章揭晓用于保持正常阅读时的未知感，不是内容加密。仓库源码和 PDF 可以直接查看全文；本网站不包含总决赛结果。当前阅读与揭晓状态保存在本次页面会话中，刷新后从序章重新开始。
